# トラブルシューティング

WeasyPrintと日本語組版で実際に踏んだ問題と、その対処。
症状から探して、原因を理解したうえで直す。

## 目次や相互参照のページ番号が全部「1」になる

**原因**: どこかの要素に `counter-reset: page` を指定している。WeasyPrintではこれが
`target-counter(attr(href), page)` の解決を壊し、すべての参照が1を返すようになる。
しかも肝心のノンブル自体はリセットされないので、指定する利点がない。

**対処**: `counter-reset: page` を使わない。前付をローマ数字にしたい場合は
`@page frontmatter { @bottom-center { content: counter(page, lower-roman) } }` のように
**表示形式だけ**を変える（値は通し番号のまま）。

## コードのインデントと空行が消える

**原因**: Pygmentsの出力を `BeautifulSoup(marked, "html.parser")` で再パースして
DOMに差し戻すと、空白のみのテキストノードが捨てられる。行頭のインデントがこれに当たる。

**対処**: `build_pdf.py` はDOMにプレースホルダだけを置き、シリアライズ後に文字列として
着色済みHTMLを差し込んでいる。この構造を崩さない。似た加工を足すときも、
コードの中身をBeautifulSoupに通し直さないこと。

## 章の全ページから柱とノンブルが消える

**原因**: `.chapter { page: opener }` のように章全体へ名前付きページを当てている。
`page` は要素が流れる**すべてのページ**に適用されるので、章の本文ページまで扉扱いになる。

**対処**: 扉部分だけを別要素（`.ch-opener`）に切り出し、そこにだけ `page: opener` と
`break-after: page` を指定する。章のコンテナ側には `page` を書かない。

## 表紙が上半分しか塗られない

**原因**: `.cover { height: 100% }` は祖先要素に高さが無いと解決されず、中身の高さになる。
flexの `flex: 1 1 auto` も伸びない。

**対処**: ページ高さを実寸で渡す。`build_pdf.py` はプリセットから `--page-h` を注入し、
`.cover { height: var(--page-h) }` としている。判型を足すときは `height` の指定も忘れずに。

## 表紙の下に罫線だけが残る

**原因**: 著者名（`--author`）も刊記（`--meta`）も無いのに、表紙下部の区切り罫だけが出ている。

**対処**: 現在は両方空なら `.cover-bottom` ごと出力しない。代わりに `.cover.nofoot` が付き、
書名ブロックが天地中央に組み直される。表紙に要素を足すときも「空なら丸ごと落とす」を守る。

## 圏点が表示されない

**原因**: WeasyPrintは `text-emphasis` に未対応。指定しても無視される。

**対処**: `.dot` クラスは点線の傍線（`border-bottom: 1pt dotted`）で代替してある。
傍線は要素の下端に引かれるため、和文グリフの下に自然に収まる。

同様に、蛍光ペン風の `.marker` は `linear-gradient(transparent 45%, …)` で作っている。
開始位置を下げすぎる（56%以上）と、欧文混じりの行で打ち消し線のように見える。

## コードの折り返しが新しい行に見える

**原因**: 長い行が `white-space: pre-wrap` で折り返されると、続き行なのか次の文なのか
判別できない。CSSでは折り返し行だけを狙って装飾できないため、根本的な解決策がない。

**対処**: 折り返させないのが唯一の正解。判型ごとの上限（a4:72 / b5:60 / a5:48文字）に
収まるよう、変数名を短くするか明示的に改行を入れる。ビルド時に該当行が警告される。
保険としてPygmentsの `linespans` で1行=1ブロックにし、ぶら下げインデントは効かせてある。

## 側注が紙面からはみ出す

**原因**: 側注は `float: right` と負の `margin-right`（= `--sidenote-pull`）で外マージンへ
押し出している。`--sidenote-pull` がページの外マージンより大きいと紙面外に出る。

**対処**: `sidenote_pull ≦ 外マージン` を保つ。判型を追加するときは
`sidenote_pull = sidenote_w + 逃げ(4〜6mm)` で計算し、外マージンに収まるか確認する。

`--no-sidenotes` は外マージンを狭くするため、この関係が必ず崩れる。そのため
`<body class="narrow-margins">` が付き、`.narrow-margins .sidenote` が負マージンを
打ち消して本文段内に回り込ませる。判型を追加してもこの逃げ道は共通で効く。

## 囲みが不自然な位置で改ページされる

**原因**: `break-inside: avoid` を付けた要素が版面の高さより大きいと、避けられずに分割される。
逆に、直前に大きな `avoid` 要素があると、その手前に大きな空白ができる。

**対処**: 囲みの中身を短くする。長い解説は囲みの外の本文に出す。
どうしても長い場合は、その要素だけ `class="callout note"` から `break-inside: auto` に
上書きするクラスを当て、分割を許す。

## 目次に索引が載らない

**原因**: 索引セクションを本文ツリーとは別の文字列として持ったまま、あとから連結している。
目次は本文ツリーを走査して作られるので、ツリーの外にある見出しは拾えない。

**対処**: `collect_index()` の結果を `body` に append してから `build_toc()` を呼ぶ。
巻末に節を足すときも同じで、**目次生成より前に本文ツリーへ入れる**。
appendのあとは `assign_heading_ids()` を再実行して、新しい見出しにIDを振り直す。

## 巻末の柱に前章の章題が残る

**原因**: 柱は `string-set: chapter-title` を設定した見出しから引き継がれる。索引や巻末解答の
`h1` に指定がないと、直前の章の値が残り続ける。

**対処**: 巻末に独立した節を足すときは、その `h1` に
`string-set: chapter-title content(text)` を指定する。`.index h1, .answers h1` は設定済み。

## 日本語が豆腐になる

**原因**: `Noto Serif CJK JP` / `Noto Sans CJK JP` が環境に無い。

**対処**: `fc-list :lang=ja family` で確認する。無ければ
`apt-get install -y fonts-noto-cjk` を実行するか、`book.css` の `--serif` / `--sans` を
環境にあるフォントに書き換える。フォント名は `fc-list` の出力と厳密に一致させる。

## ビルドが通らない

- `ModuleNotFoundError` — `build_pdf.py` は不足パッケージを自動で `pip install` する。
  ネットワークが無い環境では事前に `pip install weasyprint beautifulsoup4 pygments` を実行する。
- `OSError: cannot load library 'gobject-2.0'` — WeasyPrintのシステム依存が不足している。
  `apt-get install -y libpango-1.0-0 libpangoft2-1.0-0 libharfbuzz0b` を入れる。
- レイアウトが想定と違う — `--keep-html` で中間HTMLを出し、ブラウザで開いて構造を確認する。
  ただしブラウザとWeasyPrintでは改ページ・floatの挙動が違うので、最終確認は必ずPDFで行う。
